À propos des prix Steam

GameLab utilise une tâche GitHub Actions pour consulter périodiquement les prix français, les promotions, les images et les descriptions des jeux présents dans catalogue.json.

Les montants affichés viennent du dernier relevé réussi — ils ne sont pas mis à jour à chaque clic. Quand un prix manque ou devient trop ancien, il est indiqué comme indisponible ou ancien, jamais estimé.

Les jeux ajoutés à un groupe Supabase sont immédiatement partagés avec ses membres. Pour actualiser automatiquement le prix d’un nouveau jeu, ajoutez également son App ID à catalogue.json sur GitHub.
